# Youtube-Clone
I created a front-end replica of the YouTube homepage using HTML and CSS. The project features a responsive header, sidebar navigation, and video grid layout similar to the original site. It helped me improve my web design skills and understand realworld layout structuring using HTML elements and CSS Flexbox/Grid.
